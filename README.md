# Banana Ball Bros - No Audio Test Package

This package is structured for GitHub Pages testing.

Important:
- `BaseballBros.js` is at the repository root.
- Game images are under `assets/`.
- Firebase browser SDK files are under `vendor/`.
- Captured audio files were intentionally omitted for this test.
- If the game requests audio, the browser may show audio 404 errors. That is expected in this package.
- If the game fails to finish loading because audio is required, we can patch the loading/audio handling next.

Upload the CONTENTS of this folder to the root of the GitHub repository.
Do not upload the outer folder itself if you want `index.html` at the repository root.
