# Banana Ball Bros — split-assets, no-audio build

This build is prepared for GitHub's 100-file-at-a-time upload limit.

Structure:
- `index.html`
- `BaseballBros.js`
- `vendor/` (Firebase files)
- `assets1/` (6 files)
- `assets2/` (5 files)
- other root files

Audio is intentionally omitted.

Upload the CONTENTS of this folder to the root of the GitHub repository. Keep `assets1`, `assets2`, and `vendor` as folders at the repository root.

`index.html` and `BaseballBros.js` have been updated to point to the split asset folders.
